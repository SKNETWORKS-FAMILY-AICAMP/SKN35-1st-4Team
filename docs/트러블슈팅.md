# 앗차차! 트러블슈팅 내역

실제로 겪고 해결한 순서대로. 각 항목은 **증상 → 원인 → 해결 → 교훈**.

## 1. 지도가 `kakao is not defined`로 빈 화면

- **증상**: 로컬에서 잘 되던 지도가 어느 날 콘솔에 401과 함께 죽음
- **원인**: 다른 프로세스가 8501을 선점해 앱이 8502로 뜸. 카카오는 **포트까지 포함한 도메인 단위**로 SDK를 허용하므로 `localhost:8501`만 등록된 상태에서 8502는 차단
- **해결**: 포트 고정 실행 + SDK 로드 실패 시 현재 주소와 등록 안내를 지도 자리에 표시하는 오류 패널 추가
- **교훈**: 외부 SDK의 도메인 화이트리스트는 "포트가 다르면 다른 도메인"

## 2. 이름으로 중복 제거했더니 주차장이 사라짐

- **증상**: 망원 노상공영주차장이 8곳 → 1곳으로 줄어듦
- **원인**: 같은 이름의 노상 구간이 실제로 여러 곳인데 이름만으로 dedupe
- **해결**: 좌표가 없을 때만 주소까지 일치해야 중복으로 판정
- **교훈**: 현실 데이터의 "같음"은 이름이 아니라 이름+위치

## 3. 주차면이 `여유 7 / 총 1`

- **증상**: 실시간 여유가 총 면수보다 큼
- **원인**: 목록 크롤링의 capacity가 오래된 값, 실시간 API가 최신
- **해결**: 실시간 값이 있으면 capacity도 실시간 쪽으로 덮어씀

## 4. Material 아이콘이 `my_location` 글자로 보임

- **증상**: 아이콘 자리에 영문 아이콘명이 그대로 출력
- **원인**: 전역 웹폰트 CSS가 아이콘 폰트까지 덮어씀. 아이콘 종류마다 testid가 달라(`stIconMaterial`, `stExpanderIcon`…) 하나만 제외해선 부족
- **해결**: `[data-testid$="Icon"]` 접미사 셀렉터로 일괄 제외. 이후 폰트를 테마 설정(config.toml)으로 옮기며 원인 자체 제거

## 5. 수집기를 돌려도 화면은 "데이터 없음"

- **증상**: CSV를 새로 만들었는데 앱은 여전히 없다고 표시
- **원인**: `@st.cache_data(ttl=1800)`가 "없음" 결과를 캐시
- **해결**: 캐시 함수 인자에 **파일 mtime**을 넣어 파일이 바뀌면 키가 바뀌게
- **교훈**: 파일 기반 로더의 캐시 키에는 파일 상태를 포함할 것

## 6. 지도 마커 드래그가 두 번이나 안 됨

- **증상**: 드래그 코드를 넣었는데 마커가 안 움직임 → 고쳤는데 또 안 움직임
- **원인**: ① `CustomOverlay`는 기본 `clickable: false`라 마우스 이벤트가 지도로 통과 ② 그걸 고치자 이번엔 오버레이가 커서를 잡아 지도 `mousemove`가 발화 안 함
- **해결**: DOM `mousemove` + `projection.coordsFromContainerPoint()`로 화면 픽셀→좌표 직접 변환, 놓으면 `postMessage`로 파이썬에 전달
- **교훈**: "시뮬레이션으로 동작 확인"은 검증이 아니다 — 실제 마우스로 확인해야 한다 (처음에 postMessage만 흉내내고 동작한다고 오판)

## 7. 시간대 분석이 사실은 DB를 안 쓰고 있었음

- **증상**: (없음 — 화면은 멀쩡했음)
- **원인**: pymysql은 SQL 내 `%`를 `%%`로 escape해야 하는데 params 없이 보내면 아무도 되돌리지 않아 `%%`가 그대로 TiDB에 도착 → 문법 오류. 그런데 **조용한 CSV 폴백이 예외를 삼켜** 몇 주간 아무도 모름
- **해결**: `%` 대신 `MOD()` 사용. 그리고 폴백 정책 자체를 변경 — DB 설정이 있는데 실패하면 숨기지 않고 화면에 원인 표시 후 정지
- **교훈**: **조용한 폴백은 버그 은닉처**. 폴백은 "설정이 없을 때"만, "실패했을 때"는 티 나게

## 8. 민원 게시판이 "DB를 쓰는 척"만 함

- **증상**: 화면은 정상인데 DB의 새 데이터가 반영 안 됨
- **원인**: 쿼리가 `FROM FAQ`(실제 테이블은 complain 계열) → 매번 실패 → `except: pass` → CSV 폴백
- **해결**: 테이블명 수정 + 예외를 삼키지 않고 표시
- **교훈**: #7과 동일 패턴. `except: pass`는 코드리뷰에서 무조건 의심

## 9. 넣은 SVG 그림이 하나도 안 보임

- **증상**: 히어로 마크·일러스트를 넣었는데 화면에 없음. 사용자는 "뭐가 달라진 건지 모르겠다"
- **원인**: `st.html`이 DOMPurify로 새니타이즈하며 **인라인 `<svg>`를 통째로 제거**
- **해결**: 4가지 방식을 프로브 앱으로 실측 → base64 **data URI `<img>`만 통과** 확인, 전면 전환. 애니메이션은 SVG 문서 내부 `<style>`로 이동
- **부수 사고 2건**: ① CSS 주석에 `<img>`라고 적자 스타일 블록 전체가 삭제돼 디자인이 통째로 날아감 ② `animation-fill-mode: both`가 애니메이션 미실행 시 시작 상태(투명)에 갇혀 체크 표시가 안 보임 → 투명도 대신 크기 변화로 변경
- **교훈**: 렌더링 파이프라인에 새니타이저가 있으면 "코드에 있다 ≠ 화면에 있다". 최종 화면을 봐야 검증이다

## 10. 배포하니 `load_dotenv` 의존성이 위험한 상태

- **증상**: (배포 전 점검에서 발견)
- **원인**: `requirements.txt`의 `dotenv>=0.9.9`는 **다른 패키지** (필요한 건 `python-dotenv`). 로컬은 둘 다 깔려 있어 우연히 동작. `numpy` 누락, 클라우드에서 못 쓰는 selenium 등 포함
- **해결**: 런타임 전용 슬림 목록으로 재작성, 깨끗한 가상환경에서 전체 import 검증
- **교훈**: requirements는 "로컬에 깔린 것"이 아니라 "새 기계에서 앱이 뜨는 최소"를 적는 것

## 11. 배포하니 지도만 하얗게 (로컬은 정상)

- **증상**: Secrets까지 넣었는데 지도가 빈 화면. 콘솔: `Mixed Content: requested an insecure script 'http://t1.daumcdn.net/...'` + `kakao.maps.LatLng is not a constructor`
- **원인**: 지도 HTML이 srcdoc iframe이라 `location.protocol`이 `about:` → 카카오 SDK 로더가 https 판정에 실패해 내부 번들을 **http://로** 요청 → https 페이지에서 브라우저가 차단. 로컬(http)에선 http→http라 안 걸림
- **해결**: SDK 로드 직전 `document.write`를 가로채 `http://`→`https://` 치환
- **교훈**: srcdoc iframe은 프로토콜 정보가 없다. "로컬에서 되는데 배포에서 안 되는" 지도/SDK 문제는 프로토콜부터 의심

## 12. Secrets를 넣었는데도 계속 안 됨

- **증상**: "다 했는데 왜 안 돼" — 화면 그대로
- **원인**: 푸시(01:56)와 Secrets 저장이 모두 **앱이 빌드된 시각(01:30) 이후**. 자동 재배포가 걸리지 않아 옛 인스턴스가 계속 돎. 화면에 남은 옛 안내 문구가 결정적 단서
- **해결**: Manage app → Reboot app 한 번으로 최신 코드 + Secrets 동시 반영
- **교훈**: 배포 화면의 문구가 "지금 어느 버전이 도는지"를 알려주는 지문이다. 그리고 이런 상황 자체를 없애려 **설정 진단 화면**(값은 숨기고 출처만 표시)을 앱에 내장

## 13. 그 외 잔사고 모음

| 증상 | 원인 → 해결 |
|---|---|
| 절약 배너 "40,000원 아껴요" 과장 | 요금 미공개 주차장이 계산상 0원 → base_fee 있는 곳만 후보 |
| 조건 초기화해도 검색창에 글자 잔류 | `session_state.pop()`은 text_input 화면값을 못 되돌림 → 기본값 직접 대입 |
| 히어로 배너 윗부분 잘림 | 상단 툴바 60px > 본문 여백 35px → 74px로 |
| 메트릭 값 `2…` 잘림 | 내부 래퍼까지 `white-space` 해제 + clamp 폰트 |
| 사이드바 로고가 안 보일 만큼 작음 | `st.logo`가 94×24로 축소 → size="large" + 사이드바 본문에 브랜드 블록 별도 배치 |
| 로컬이 갑자기 `OperationalError` | 비밀번호 로테이션 후 로컬 `.env` 미갱신 (정상 동작 — 양쪽 갱신 필요) |
| 머지 후 작업 소실 | 앞선 세션 커밋이 dangling → `git checkout <hash> -- 파일` 로 복구. 이후 `git rm --cached` 실수도 한 번 — 스테이징 조작 전 `git status` 확인 습관 |
