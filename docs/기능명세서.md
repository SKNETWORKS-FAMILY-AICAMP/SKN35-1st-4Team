# 앗찻차! 기능명세서

버전: 1.0 (2026-07-28) · 배포: https://atchacha.streamlit.app

표기 — **입력**: 사용자가 주는 것 / **처리**: 시스템이 하는 일 / **출력**: 화면에 보이는 것

## F-01 내 위치 설정

| 항목 | 내용 |
|---|---|
| 화면 | 홈 (사이드바 + 지도 상단, 버튼 2곳) |
| 입력 | ① GPS 버튼 클릭 ② 지도의 파란 마커 드래그 ③ 위도·경도 직접 입력 ④ 랜드마크 칩(광화문광장 등 7곳) |
| 처리 | 브라우저 Geolocation API(CCv2 컴포넌트) 또는 postMessage 브리지로 좌표 수신 → `st.session_state` 저장 |
| 출력 | 지도 중심 이동, 파란 펄스 마커 + 판정 반경 원 |
| 예외 | GPS는 localhost·HTTPS에서만 동작(브라우저 정책). 거부 시 안내 문구 + 대체 입력 유도 |

## F-02 단속 위험 판정

| 항목 | 내용 |
|---|---|
| 화면 | 홈 「여기 세워도 될까?」 |
| 입력 | F-01의 위치, 판정 반경(50~500m, 기본 100m) |
| 처리 | 반경 내 누적 단속 건수 + 최근접 CCTV 거리 계산 (`common/risk_data.assess_location`) |
| 판정 기준 | **위험**: 단속 10건↑ 또는 CCTV 50m 이내 · **주의**: 단속 1건↑ 또는 CCTV 150m 이내 · **기록 없음**: 둘 다 아님 |
| 출력 | 반원 게이지(바늘 애니메이션) + 등급 배지 + 근거 수치 3종(단속 건수·CCTV 거리·위치 오차) |
| 데이터 | `ENFORCEMENT_HISTORY` 232,853건, `CCTV_INFO` 196대 |

## F-03 절약 배너

| 항목 | 내용 |
|---|---|
| 화면 | 홈 지도 바로 아래 (항상 표시, 팝업 아님) |
| 입력 | F-02 판정 결과, 주차 예정 시간 |
| 처리 | 위험/주의면: 예상 과태료(일반 4만원) − 근처 최저가 주차장 예상요금. **요금 정보가 실제로 있는(base_fee 존재) 주차장만** 후보 |
| 출력 | "앗찻차! 여기 세우면 40,000원인데, N원 아껴요" + 주차장명·요금·도보 시간. 동전 낙하 애니메이션. 기록 없음이면 초록 배너로 전환 |
| 정책 | 불법주정차를 유도하지 않는다 — 항상 합법 대안을 함께 제시 |

## F-04 통합 지도

| 항목 | 내용 |
|---|---|
| 화면 | 홈 상단 (지도 3 : 목록 1) |
| 레이어 | 주차장(공영 초록/민영 주황 P마커) · 단속 다발구역(히트 블롭) · 단속 CCTV(보라, 기본 꺼짐) · 내 주차 기록(분홍) · 내 위치(파랑 펄스) |
| 다발구역 표현 | 150m 격자 집계를 원형 블롭으로. 건수 비율에 따라 반지름 0.55~1.0×, 4단계 색. 최다 구역은 맥동 애니메이션. 클릭 시 누적 건수 말풍선 |
| 목록 패널 | 이름·주소 검색, 내 위치 있으면 거리순 정렬 + km 표시, 행 클릭 → 지도 이동 |
| 기타 | 마커 클릭 말풍선(요금·운영·주차면), 범례 카드(색 견본 + 개수) |

## F-05 주차장 검색·추천

| 항목 | 내용 |
|---|---|
| 화면 | 홈 「가까운 주차장」 |
| 입력 | 키워드, 주차 시간(0.5~12h), 무료만, (고급) 자치구·구분·운영중만 |
| 처리 | `common/recommend.rank_parking_lots` — 거리 0.5 · 여유 0.3 · 요금 0.2 가중 정규화 점수 |
| 예상요금 | 기본요금 + ⌈(시간−기본시간)÷추가단위⌉×추가요금, 일 최대요금 상한 |
| 출력 | 요약 지표 4종 → 정렬 선택(추천/요금/여유/거리/이름) → **카드 6장**(순위 배지·요금 대형 표기·주차면 잔여 막대) → 전체 표(접힘) → CSV 다운로드 |
| 예외 | 요금 미공개 주차장은 "요금 정보 없음"으로 구분(0원 오인 방지) |

## F-06 시간대 분석

| 항목 | 내용 |
|---|---|
| 처리 | 반경 내 단속을 0~23시로 집계 (DB에서 `ROUND(좌표,5)+GROUP BY` 사전 집계 후 하버사인 필터) |
| 출력 | 막대그래프 + "이 구역은 N시 전후 단속 집중" 문구 |
| 정책 | 뜸한 시간대를 안전하다고 말하지 않음 — 단속 빈도의 증거로만 제시 |

## F-07 회원가입·로그인

| 항목 | 내용 |
|---|---|
| 화면 | 로그인 (비로그인 시에만 메뉴 노출) |
| 처리 | pbkdf2_sha256(20만회+salt) 해시, `hmac.compare_digest` 비교. DB 미설정 시 SQLite 자동 전환 |
| 규칙 | 아이디 영문·숫자·밑줄 3~20자, 비밀번호 8자↑ |
| 세션 | `st.session_state` — 새로고침하면 로그아웃(의도된 설계) |
| 로그인 후 | 메뉴가 「내 주차 기록」으로 교체, 사이드바에 계정 위젯 |

## F-08 주차 기록 (마이페이지)

| 항목 | 내용 |
|---|---|
| 입력 | 주차장 선택(좌표 자동) 또는 주소 직접 입력, 일시, 유료 여부, 메모 |
| 출력 | 요약 지표 4종, 누적 절약 리포트(기록×4만원), 기록 지도(유료/무료 색), 기록 표, 삭제 |
| 보안 | 삭제 쿼리에 `user_id` 조건 포함 — 남의 기록 삭제 불가 |
